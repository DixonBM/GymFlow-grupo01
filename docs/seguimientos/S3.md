## 4. Conexión y manejo de fallos

La responsable no administra Redis ni tiene acceso directo a MongoDB. Un compañero maneja Redis en Docker y el profesor controla el servicio del servidor. La responsable reporta que MongoDB y Redis funcionan correctamente. Confirmó que recargó la página y los datos permanecieron guardados, lo que acredita su conservación desde la interfaz. No se inspeccionaron directamente los documentos de MongoDB. Las comprobaciones MISS/HIT y caída/recuperación no fueron ejecutadas por la responsable; Redis es administrado por el profesor.

Las pruebas de Docker deben indicar responsable, fecha, configuración y resultados; sus resultados corresponden a ese ambiente. No se confunden con pruebas del servidor universitario.
