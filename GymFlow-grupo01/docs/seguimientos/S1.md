## Decisiones técnicas

- **PHP 8.3** (pantallas y lógica) + HTML/CSS. No React ni Node.js.
- **MongoDB** persiste seis colecciones con datos multi-gimnasio separados mediante `gimnasioId`.
- **Redis** cachea indicadores del dashboard por gimnasio con TTL predeterminado de 60 segundos; al guardar, PHP invalida la clave. Sin Redis el sistema consulta MongoDB.
- **SQLite excluido** según indicación del profesor.
- Los datos sintéticos se generan al inicializar; no subir secretos ni contraseñas.
- Fuera de este MVP: QR, rutinas, agenda, máquinas y pagos reales de bancos.
